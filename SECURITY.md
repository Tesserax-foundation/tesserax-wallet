# Security

Report vulnerabilities of the wallet, its extension or its desktop application privately, on the
repository of the chain: **Security → Report a vulnerability** on
[`Tesserax-labs/tesserax`](https://github.com/Tesserax-labs/tesserax/security). They are rewarded by the bug
bounty of Tesserax: [docs/bug-bounty.md](https://github.com/Tesserax-labs/tesserax/blob/main/docs/bug-bounty.md).
